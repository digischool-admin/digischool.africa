**Architecture TRAÇABLE**:

**8 Questions catégorisées**:

2. **Q2 - Domaines d'intérêt** (multiple): gestion_projet, data, excel, powerbi, leadership, marketing, rh, digital

4. **Q4 - Objectif formation**: découverte | approfondissement | certification | reconversion
5. **Q5 - Contexte usage**: application_immédiate | évolution_interne | recherche_emploi | projet_personnel
6. **Q6 - Temps disponible**: flexible | modéré | intensif | immersif
7. **Q7 - Formations antérieures**: jamais | quelques | plusieurs | nombreuses
8. **Q8 - Style apprentissage**: théorie | pratique | mixte | projet

**Scoring Algorithm**:
```javascript
// Score pour chaque formation
Object.keys(formations).forEach(formationKey => {
  let score = 0;
  
  // +3 points si niveau correspond
  if (formation.level.includes(profile.experienceLevel)) {
    score += 3;
  }
  
  // +5 points par keyword matching (intérêts fonctionnels)
  // +4 points si rôle correspond
  // +4 points si intention correspond
  // +3 points si contexte correspond
  
  scores[formationKey] = score;
});

// Trier par score décroissant
recommended = sortByScore(scores);
```

**Diagnostic textuel JUSTIFIÉ**:
```javascript
generateDiagnostic() {
  // Chaque phrase est TRAÇABLE à une question
  "Expérience: Vous débutez..." → Q1 answer
  "Domaines d'intérêt: Data, Excel" → Q2 answers
  "Contexte: Collaborateur opérationnel" → Q3 answer
  "Objectif: Certification professionnelle" → Q4 answer
}
```

**Prioritization LOGIQUE**:
- 🥇 PRIORITÉ: Score > 15
- 🥈 COMPLÉMENTAIRE: Score 10-15
- 🥉 AUSSI INTÉRESSANT: Score 5-10
