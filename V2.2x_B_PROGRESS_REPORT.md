### 2. INFRASTRUCTURE BACKEND — Supabase Client ✅ (100%)

**Fichier créé**: `/assets/supabase-client.js` (8.3KB)

**API complète** (`window.DigiSchoolDB`):

#### Méthodes implémentées:
1. ✅ `isAvailable()` — Check config Supabase
2. ✅ `saveLead(data)` — Enregistrer leads (email, source, metadata, consent)
3. ✅ `createPaymentRequest(data)` — Créer demande paiement (email, invoice_id, amount, items)
4. ✅ `uploadPaymentProof(paymentRequestId, file)` — Upload preuve dans Storage
5. ✅ `createEntitlement(data)` — Créer droits d'accès (email, course_id, modules_unlocked, active_until)
6. ✅ `submitCustomTraining(data)` — Demandes formation B2B sur-mesure
7. ✅ `submitIdea(data)` — Boîte à idées B2C
8. ✅ `logAction(action, details)` — Audit log admin

**Fallback mode**:
- ✅ Si Supabase non configuré → mode graceful degradation
- ✅ Leads/ideas/custom training → fallback `mailto:`
- ✅ Payment requests → génération ID local
- ✅ Console logs informatifs

**Tables Supabase attendues**:
```sql
CREATE TABLE leads (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  email TEXT NOT NULL,
  source TEXT,
  metadata JSONB,
  consent BOOLEAN DEFAULT true,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

CREATE TABLE payment_requests (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  email TEXT NOT NULL,
  invoice_id TEXT UNIQUE NOT NULL,
  amount INTEGER NOT NULL,
  items JSONB NOT NULL,
  status TEXT DEFAULT 'pending',
  created_at TIMESTAMPTZ DEFAULT NOW()
);

CREATE TABLE payment_proofs (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  payment_request_id UUID REFERENCES payment_requests(id),
  storage_path TEXT NOT NULL,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

CREATE TABLE entitlements (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  email TEXT NOT NULL,
  user_id UUID,
  course_id TEXT NOT NULL,
  modules_unlocked TEXT[] DEFAULT '{}',
  active_until TIMESTAMPTZ,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

CREATE TABLE custom_training_requests (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  company TEXT NOT NULL,
  contact TEXT NOT NULL,
  email TEXT NOT NULL,
  phone TEXT,
  sector TEXT,
  headcount INTEGER,
  needs_text TEXT NOT NULL,
  attachments TEXT[],
  status TEXT DEFAULT 'pending',
  created_at TIMESTAMPTZ DEFAULT NOW()
);

CREATE TABLE ideas_box (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  url TEXT NOT NULL,
  description TEXT NOT NULL,
  email TEXT,
  status TEXT DEFAULT 'pending',
  created_at TIMESTAMPTZ DEFAULT NOW()
);

CREATE TABLE audit_log (
  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
  action TEXT NOT NULL,
  details JSONB,
  created_at TIMESTAMPTZ DEFAULT NOW()
);
```

**RLS Policies** (à configurer):
- Leads: INSERT public, SELECT/UPDATE/DELETE admin only
- Payment_requests: INSERT public, SELECT own email, UPDATE/DELETE admin
- Entitlements: SELECT own email, INSERT/UPDATE/DELETE admin
- Custom_training_requests: INSERT public, SELECT/UPDATE admin
- Ideas_box: INSERT public, SELECT/UPDATE admin
- Audit_log: INSERT/SELECT admin only
