## 🛠️ TROUBLESHOOTING & SUPPORT

### If Pages Show 404
**Likely Cause**: Browser cache or CDN propagation delay  
**Solution**:
1. Hard refresh: Ctrl+Shift+R (Windows) or Cmd+Shift+R (Mac)
2. Clear browser cache completely
3. Try incognito/private browsing mode
4. Wait 5-10 minutes for global CDN propagation

### If Business Rules Violated
**Likely Cause**: Cached version or manual edit after deployment  
**Solution**:
1. Check GitHub commit history for unexpected changes
2. Verify `.nojekyll` file still present
3. Re-run QA tests: `cd qa && npx playwright test`
4. Review GitHub Actions logs for test failures

### If QA Tests Fail
**Likely Cause**: Recent code changes or network issues  
**Solution**:
1. Check GitHub Actions logs for specific failures
2. Re-run workflow manually
3. Verify test expectations match current production
4. Update tests if business rules changed intentionally

### Emergency Rollback
**If critical issue found in production**:
```bash
# Option 1: Revert last commit
git revert HEAD
git push origin main

# Option 2: Rollback multiple commits
git reset --hard origin/main~18
git push --force origin main

# GitHub Pages will auto-redeploy previous version
```
